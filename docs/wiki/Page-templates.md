# Page templates

<!-- cspell:ignore UAMS -->

Written against v1.10.2.

Choose a template in the page editor's **Template** setting. The theme adds these to the Genesis defaults.

| Template | File | What it does |
| --- | --- | --- |
| Posts Home | `home.php` | Lists posts, each title as an unlinked heading, with a **Read More** button after each excerpt |
| Archive | `page_archive.php` | Replaces the page content with the Genesis site map |
| Blog | `page_blog.php` | The Genesis blog listing |
| Modules | `templates/modules.php` | Full-width page built from the **UAMS Modules** field instead of the editor content; see [Building a page](Building-a-page.md) |
| Landing | `templates/page_landing.php` | The page title is kept for screen readers and hidden visually |
| Marketing Landing Page | `templates/marketing.php` | Uses the **Marketing Landing Page Header Options** instead of the usual header options, and drops the primary navigation, the breadcrumbs, the child-page list and the post meta. Fewer blocks are offered; see [Blocks](Blocks.md) |

The header options each template offers are listed in [Page and post options](Page-and-post-options.md).
