# Building a page

<!-- cspell:ignore UAMS -->

Written against v1.10.2.

At the end of this guide a page has a template, a header and its content, built either from UAMS blocks in the editor or from modules.

1. **Create the page** in the dashboard under **Pages**, **Add New**, and give it a title.
2. **Choose a template** in the editor's **Template** setting. Leave the default for an ordinary page. Choose **Modules** to build the page from modules instead of blocks. The choices are listed in [Page templates](Page-templates.md).
3. **Set the header** in the **Header Options** panel. **Title Options** is **Normal** by default; **Graphic**, **Hero** and **Marketing Landing Page** each show the fields they need. See [Page and post options](Page-and-post-options.md).
4. **Add the content.**
   - On an ordinary page, open the block inserter and type `uams` to list the theme's blocks, then add one and fill in its fields. Use **UAMS Section** to group headings, text and images. See [Blocks](Blocks.md).
   - On a page using **Modules**, add rows to the **UAMS Modules** field, choosing a layout for each, in the order they should appear.
5. **Set the page attributes** if the page starts a subsection or should be left out of the generated menus, in **UAMS Page Attributes**.
6. **Preview, then publish.**

**Note:** if a block or field this guide mentions is not there, see [Troubleshooting](Troubleshooting.md).
